# TecBoard

> Uma aplicação interativa para gerenciar e organizar eventos por categorias/temas

[![React](https://img.shields.io/badge/React-19.2-blue?logo=react)](https://react.dev)
[![Vite](https://img.shields.io/badge/Vite-8.0-purple?logo=vite)](https://vitejs.dev)

## Sobre o Projeto

TecBoard é uma aplicação web desenvolvida com **React 19** e **Vite** durante um curso da **Alura**, com o objetivo de praticar conceitos fundamentais da biblioteca.

A aplicação permite criar e visualizar eventos organizados por categorias como Front-end, Back-end, DevOps, Inteligência Artificial, Data Science e Cloud.

## Funcionalidades

- ✅ **Formulário Dinâmico**: Adicione novos eventos com título, data, imagem e categoria
- ✅ **Organização por Temas**: Eventos automaticamente agrupados por categorias
- ✅ **Cards**: Visualização dos eventos com imagens e informações
- ✅ **Interface Responsiva**: Design adaptável para diferentes tamanhos de tela
- ✅ **Componentes Reutilizáveis**: Arquitetura modular e escalável

## Tecnologias

- **React 19.2** - Biblioteca JavaScript para UI
- **Vite 8.0** - Build tool e dev server ultra-rápido
- **CSS3** - Estilização com componentes separados
- **Node.js** - Runtime JavaScript

## Pré-requisitos

- Node.js (v16 ou superior)
- npm ou yarn

## Conceitos React Aprendidos

- **Componentes Funcionais**: Uso exclusivo de componentes modernos
- **Hooks**: `useState` para gerenciamento de estado
- **Props**: Comunicação entre componentes pai-filho
- **Renderização Condicional**: Exibição dinâmica baseada em condições
- **Array Methods**: `map()`, `filter()`, `find()`, `some()`
- **Event Handling**: Submissão de formulários e callbacks
- **Estado Imutável**: Padrões corretos com spread operator

## Créditos

Este projeto foi desenvolvido acompanhando o curso **"React 19: JSX, componentes, form action e useState"** da Alura.

O código foi construído seguindo as aulas e orientações do curso, com fins educacionais.
